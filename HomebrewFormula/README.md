# Homebrew Tap for AngkorFetch

To use this tap:

```bash
brew tap AMRSKH/tap https://github.com/AMRSKH/homebrew-tap
brew install angkorfetch
```

Or create a repo `AMRSKH/homebrew-tap` on GitHub and copy `angkorfetch.rb` into it, then users can run:

```bash
brew install AMRSKH/tap/angkorfetch
```
